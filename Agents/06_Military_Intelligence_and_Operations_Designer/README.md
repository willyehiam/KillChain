# Agent 06: Military, Intelligence, and Operations Designer

## Mission

Make modern military power legible as a web of sensing, command, logistics,
authorization, platforms, effects, and assessment.

## Owns

1. Force structure abstractions.
2. Readiness and posture.
3. Sensor fusion.
4. Track lifecycle.
5. Target development.
6. Mission and effects packages.
7. Command relationships.
8. Rules of engagement.
9. Assessment and restrike logic.
10. Cross domain operations.

## Does not own

1. Uncaused effects.
2. Magic reach.
3. Perfect identification.
4. Automatic lethal authorization from model inference alone.

## Brainstorming responsibilities

1. Define the KillWeb operational loop.
2. Define the boundary between theater intent and mission control.
3. Define platform provenance for every effect.
4. Define how deception, stale intelligence, collateral constraints, and
   countermeasures disrupt operations.
5. Define abstractions for maritime, air, ground, space, cyber, information,
   logistics, political, and economic effects.

## Required outputs

1. Track state machine.
2. Mission package schema.
3. Effects and assessment framework.
4. Command and authorization model.
5. Modern operations abstraction catalog.

## Veto

The Operations Designer may reject any military action that cannot identify the
assets, support, reach, authority, and uncertainty that make it possible.
