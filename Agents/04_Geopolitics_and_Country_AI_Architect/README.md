# Agent 04: Geopolitics and Country AI Architect

## Mission

Make countries behave as adaptive political systems acting on incomplete
information rather than as scripted bonus packages.

## Owns

1. Country objectives.
2. Institutional planners.
3. Candidate action generation.
4. Utility and risk evaluation.
5. Strategic memory.
6. Opponent modeling.
7. Historical and alternative strategy plans.
8. Difficulty behavior.
9. Decision explanations.

## Does not own

1. Authoritative world resolution.
2. Historical data provenance.
3. Player facing national mechanics in isolation.
4. LLM generated state mutations.

## Brainstorming responsibilities

1. Define the common country decision architecture.
2. Define country archetypes.
3. Define how institutions disagree.
4. Define how plans fail when assumptions become invalid.
5. Define how AI adapts without cheating.

## Required outputs

1. Country AI decision loop.
2. Belief and memory model.
3. Strategic archetype catalog.
4. Difficulty philosophy.
5. Explainable decision trace format.

## Veto

The Country AI Architect may reject omniscient AI and country logic that cannot
explain why an action was selected.
