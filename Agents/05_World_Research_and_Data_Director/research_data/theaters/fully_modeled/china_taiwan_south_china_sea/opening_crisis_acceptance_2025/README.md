# Opening Crisis Acceptance Fixture

Status: synthetic headless research probe.

This fixture tests whether the opening Taiwan crisis can produce a legible chain
of strategic decisions across the six deep opening countries. It is not a
production simulation, a balance model, or a prediction that a blockade occurs.

The probe begins at the frozen September 1, 2025 bookmark. A campaign creation
input may select the hypothetical branch in which a later Chinese exercise
persists into a coercive blockade. That branch is an input to the test and never
opening faction knowledge.

The fixture must prove five things before more horizontal research is useful:

1. Every country can refuse, delay, condition, or escalate participation.
2. Treaty consultation, domestic authority, access, force allocation, and
   operational tasking are different transitions.
3. A plan cannot spend capability that was not conserved from a national pool.
4. World truth and each faction belief remain different records.
5. The same state, commands, data version, and seed produce the same event log.

Synthetic capability tokens exist only to exercise conservation. They are not
claims about real force quantities.
