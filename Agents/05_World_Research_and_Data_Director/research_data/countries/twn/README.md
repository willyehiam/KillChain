# Taiwan Country Dossier

## Status

Tier A research foundation for the 1 September 2025 bookmark. This directory contains operating structure only. It does not claim that government, military, infrastructure, or political records are complete.

## Scope

All armed services, joint commands, reserves, Coast Guard, civil defense organizations, and strategically relevant government controlled support capacity.

## Research interfaces

1. `profile.json` is the current dossier summary.
2. `research_manifest.json` is the machine readable file and gate registry.
3. `lane_coverage.json` is the authoritative lane progress matrix.
4. `evidence_registry.json` is an intentionally empty local source and claim staging registry.
5. `bookmark_state.json` is an intentionally empty integration surface for the opening state.
6. `WORK_PACKAGES.md` defines bounded parallel research packages.
7. `force_ledger/manifest.json` owns complete military accounting status.

## Truth rule

No value is populated merely because it is commonly known. A factual value enters this dossier only through a dated source, an atomic claim, normalization, and review.
